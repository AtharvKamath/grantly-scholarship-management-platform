# 🎓 GRANTLY – Unified Scholarship Discovery & Management Platform

**Your Future Deserves Every Opportunity.**

GRANTLY is an AI-powered scholarship discovery and management platform designed to help students find suitable scholarships, check eligibility, receive personalized recommendations and manage their scholarship applications in one place.

Our goal is to make scholarship opportunities easier to discover and access for every student.

---

## 🚀 Key Features

### 👨‍🎓 Student Portal
- Student registration and login.
- Google Authentication using Firebase.
- Email OTP verification.
- Personalized student dashboard.
- Manage academic and personal profiles.
- Upload and manage student documents.

### 🔍 Scholarship Discovery
- Explore available scholarships.
- Search scholarships by name and category.
- Filter scholarships based on eligibility.
- View scholarship amounts and deadlines.
- Save interesting scholarships.

### 🤖 AI-Powered Recommendations
- Personalized scholarship recommendations.
- Profile-based scholarship matching.
- Eligibility checking.
- Match percentage and explanations.
- AI-powered scholarship assistance through GRANTLY AI Assistant.

### 📋 Application Management
- Track scholarship applications.
- Monitor application status.
- Manage saved scholarships.
- View upcoming scholarship deadlines.

### 🛡️ Admin Dashboard
- Separate administrator portal.
- Manage scholarship information.
- View and manage student records.
- Monitor scholarship applications.
- View platform statistics and reports.

### 📧 Contact & Support
- Contact form for student queries.
- Email notifications and communication.

## ⚙️ Installation and Setup

### 1. Clone the Repository

```bash
git clone https://github.com/YOUR_USERNAME/grantly-scholarship-management-platform.git
```

### 2. Open the Project

```bash
cd grantly-scholarship-management-platform
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Configure Environment Variables

Create a `.env` file in the project root and add your required Firebase and Gemini configuration.

```env
VITE_FIREBASE_API_KEY=your_firebase_api_key
VITE_FIREBASE_AUTH_DOMAIN=your_auth_domain
VITE_FIREBASE_PROJECT_ID=your_project_id
VITE_FIREBASE_STORAGE_BUCKET=your_storage_bucket
VITE_FIREBASE_MESSAGING_SENDER_ID=your_sender_id
VITE_FIREBASE_APP_ID=your_app_id
```

Configure Gemini API keys, email service credentials and other private secrets on the backend. Never expose private API keys in frontend code.

### 5. Run the Application

```bash
npm run dev
```

Open the local development URL shown in your terminal.
